# AI 协同证据索引

本目录目前提供整理摘要与归档规范，不包含原始对话完整导出，也不代表已经满足赛事“至少三条完整 Prompt 链”的要求。

## 已有记录

- [早期开发整理摘要](development-summary.md)：根据当前真实会话整理，记录用户决策、修改、验证和限制。
- 原始导出、截图或录屏：待参赛者从使用的 AI 工具保存后补充。不要仅保留最终 Prompt。

## 每条迭代链需记录

1. 原始需求与完整上下文。
2. AI 的建议，以及人类选择、否决或修正的理由。
3. 对应实现文件和 Git 提交编号。
4. 实际测试命令、结果及真实问题。
5. 后续修正输入、实现和复验结果。

原始材料中的密钥、密码和个人信息对外提交前脱敏。脱敏应标记，不伪造未发生的故障，不补写虚构对话，不改变历史日期。

## 后续核心链计划

| 主题 | 当前状态 |
| --- | --- |
| 通知提取与原文证据 | 已有真实交互和模拟测试，需要补齐原始材料 |
| 通知变更影响 | 尚未实现，开发时持续记录 |
| 截止提醒与异常恢复 | 已确认规则，尚未实现，开发时持续记录 |

真实登录、数据隔离及前后端联调也应记录，但不能把文档模板算作已完成的功能迭代链。

# DDL 雷达前端

React + TypeScript + Vite，图标使用 Lucide。复用已有四页原型，提供蓝白工作台界面；不使用外部字体服务，不引入额外框架。

## 启动

在仓库根目录打开终端：

```powershell
cd frontend
npm ci
npm run dev
```

访问 <http://127.0.0.1:5173>，点击“进入演示工作空间”，无需填写邮箱或密码。

解析接口需要后端。另开终端，在仓库根目录执行（先按根目录 README 安装后端依赖）：

```powershell
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Vite 将 `/api` 代理到本机 8000 端口，保留现有 `vite.config.js`，没有修改后端跨域或数据库配置。生产部署仍需配置同源反向代理。

真实解析要求后端配置可用的 DeepSeek 密钥与模型。正文会发送给 DeepSeek 并可能产生费用，请勿输入敏感资料。密钥只由后端读取，不得放入前端或任何 `VITE_` 环境变量。

## 页面与交互

### 登录页

- 桌面左右分栏，手机单栏；展示“通知→要求→行动”的计划流程。
- 邮箱和密码仅作界面预览，提供密码显隐；没有认证请求，不记录或持久化表单值。
- 登录按钮禁用并明确标注“尚未开放”。演示入口独立可用，进入时清空预览表单。
- 注册与找回密码未实现，不提供虚假可用入口。

### 事项总览

- 事项、日期、状态及提醒均为明确标注的固定演示数据，不按当前时间计算样例倒计时。
- 支持名称或类别搜索，以及全部、进行中、临期、待确认、已完成筛选。
- 统计卡针对搜索匹配范围计算；状态筛选只控制列表，列表显示实际匹配数量。
- 进行中包含尚未全部完成任务的事项，包括临期与待确认；后二者属于进行中的子集。
- 已完成任务统计、卡片进度与下一任务来自同一份内存勾选状态。
- 全部任务勾选后，事项进入已完成，不再计入进行中、临期或待确认；取消勾选后恢复其初始演示状态。
- 提醒中心入口定位到总览中的提醒样例区，不暗示存在真实消息或未读通知。

### 通知解析

- 请求 `POST /api/notices/parse`，请求体为 `{"text":"通知全文"}`。
- 响应结构与后端 `EvidenceFact`、`ParsedNotice` 对齐，检查嵌套字段、状态及原文引用。
- 区分已提取、待核对；待确认；未说明。引用逐字匹配不证明结论语义正确。
- 加载时禁止编辑和重复提交；输入变化或重新填充样例时清除旧结果与错误。
- 最长等待 60 秒；离页时取消等待。取消不保证后端模型调用已经停止或未计费。
- 分别处理网络失败、非 JSON 响应、未配置密钥、模型不可用、无效模型输出和输入校验失败。
- 点击引用会聚焦并高亮原文；重复引用定位到第一次出现的位置。
- 示例为明确标注的教学演示通知，不冒充正式赛事文件。
- 当前只解析，不保存结果，不生成真实事项或任务。

### 事项详情

- 演示任务标为 AI 建议或用户计划，均说明未关联原文，不冒充原文要求。
- 勾选仅保留在当前页面会话内；页面之间导航保留，刷新后恢复初始状态。
- 展示截止前 5 天、3 天、24 小时的计划节点，站内与邮件渠道均显示未接入。
- 不创建提醒计划，不展示发送成功。

## 响应式与可访问性设计

- 桌面工作台侧栏、解析双栏；手机导航抽屉、单栏卡片和上下排列的解析区。
- 状态使用文字和图标，临期与待确认为橙色，错误为红色。
- 提供键盘焦点提示、跳到主要内容入口、原生复选框、状态播报。
- 手机抽屉包含关闭按钮、Escape 关闭、焦点循环和背景 inert。
- CSS 遵循 `prefers-reduced-motion`；引用定位在减少动态效果时使用即时滚动。
- 以上是已实现的设计，浏览器实际表现仍需视觉与键盘验收。

- `src/api/notices.ts`：API 调用、运行时结构与引用校验、错误分类。
- `src/components/NoticeParser.tsx`：独立解析页面、请求清理与引用定位。
- `README.md`：前端使用和验收说明。
